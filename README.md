# Homebrew Tap: osidb-mcp

Homebrew formula for [osidb-mcp](https://github.com/vdanen/osidb-mcp) - MCP server to interact with OSIDB. LLMs can interface with flaws and records via MCP and natural language commands.

## Installation

```sh
brew tap vdanen/osidb-mcp
brew install osidb-mcp
```

Refer to the manpages or the
[osidb-mcp](https://github.com/vdanen/osidb-mcp) git repo for more
information on uage.

## Updating

```sh
brew update
brew upgrade osidb-mcp
```

## Supported Platforms

* any that osidb-bindings supports
